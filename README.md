## 📌 Sobre o projecto

A **Qcena** é uma plataforma angolana de divulgação e venda de produtos. O nome vem de "qualquer cena" — a ideia é que a marca não fica presa a uma categoria única de produto nem a um único modelo de negócio.

**Modelo actual (Fase 1):** produtos são adquiridos localmente, catalogados na plataforma web e nas redes sociais (Facebook, Instagram, TikTok), e o contacto com o cliente é feito directamente via WhatsApp — negociação de quantidade, preço e ponto de encontro incluída.

**Visão futura (Fase 2):** evolução para um modelo de marketplace, com fornecedores a listar produtos e divulgadores terceiros a ganhar comissão por promovê-los — um modelo próximo do AliExpress, pensado para o mercado africano.

> ⚠️ **Estado actual:** projecto em fase inicial de desenvolvimento e validação. A Qcena ainda não é uma entidade legalmente registada — é tratada como *plataforma/iniciativa* até essa formalização acontecer.
